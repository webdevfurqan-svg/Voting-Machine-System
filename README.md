# 🗳️ VotePulse — Digital Voting Machine System

VotePulse is a lightweight, fully responsive web-based digital voting application designed to simulate a real-world electronic voting machine. Built purely with standard web technologies, it allows users to cast secure votes, view candidate profiles, and get immediate visual confirmation with real-time tally tracking.

---

## ✨ Features

* **Interactive Candidate Interface:** Clean grid layout displaying candidate names, symbols, and vote buttons.
* **Instant Vote Tallying:** Real-time JavaScript state management to track and update vote counts without page refreshes.
* **Single-Vote Security Logic:** Prevents multi-voting per session using dynamic button state disabling and state tracking.
* **Responsive Modern UI:** Fully mobile-optimized interface using custom CSS Grid, Flexbox, and fluid typography.
* **Visual & Audio Feedback:** Simulates a physical voting machine with active button highlights and confirmation overlays.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic markup structure.
* **CSS3:** Custom styles, modern Flexbox/Grid layouts, custom variables, and responsive media queries.
* **JavaScript (ES6+):** DOM manipulation, state management, and event handling.
